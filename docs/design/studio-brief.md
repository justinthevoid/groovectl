# Playlist studio extension

This work extends the existing Groovectl MCP App. Preserve its cream, raspberry and olive identity, its compact player and its brief → recordings → sequence → cover navigation. It is an ordinary extension of an existing interface, not a new visual direction or a user-selected redesign.

The audience is someone curating with an agent who needs to inspect the exact recordings and approve a concrete operation. Show chapter ranges, pinned recordings and runtime constraints in the sequence and preview. Disable manual moves until the user deliberately clears the story constraints. Preserve the story when spacing artists or creating the next preview. A preview does not change Apple Music.

Backend and tool-profile limits must be explicit. A headless server has no player controls. A catalog-only profile cannot save briefs, generate artwork or apply library changes. Keep ordinary tools usable without the app. Show provider limits as local attempt caps, not live provider quotas. Keep accepted, verified and uncertain write states distinct.

Qualification uses the actual built app in the MCP Apps development host with synthetic tracks and mutations, plus server contract tests. Test desktop and phone widths, light/dark, keyboard focus, profile limits and failure recovery. The development host is not the installed ChatGPT host and does not qualify real playback, account writes or image generation. Those checks have separate receipts.

The independent finish review is scoped to these changes and their rendered states. Existing website design documentation remains separate. No new visual workshop, user approval or permanent preference is implied.
