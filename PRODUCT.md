# Groovectl product context

Groovectl is a public-source Apple Music MCP server, CLI, skill and optional interactive extension. The audience is people who use agents and want thoughtful music discovery, dependable account tools and player control. The agent supplies taste; Groovectl supplies recording identity, constraints, safe writes and verified outcomes.

The main journey is playlist studio: brief → recordings → sequence → cover. A natural-language brief is enough. Optional interviews, presets, agent suggestions and locked rerolls help people who want inspiration. Preserve private credentials, historical journals, existing tool names and installed plugin identity.

Public promises must distinguish supported code, contract tests, live account evidence and interactive player qualification. macOS native, Windows media sessions, Cider and API-only hosts have different capabilities. No universal remote, full listening archive, invented audio features, automatic paid image fallback or automatic replay of uncertain writes is promised.

The public website uses Astro 7, Svelte 5 and Starlight; it explains installation, MusicKit, capabilities, creative workflows and deployment. It contains no music credentials or account mutation endpoint. Public publication, billing and externally writable service exposure remain separate release actions. The user selected Groovectl and requested an autonomous multi-hour development/release-preparation cycle.
