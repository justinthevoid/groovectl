# Brand asset provenance

`vinyl-journey.png` is the original 1536 × 1024 alpha image generated with the built-in Codex image tool on 2026-10-15 for the user's selected surreal record-sculpture direction. It depicts fictional objects, not a product screenshot or existing album artwork. `vinyl-journey.webp` is its optimized derivative, preserving transparency. The exact prompt is in `vinyl-journey.prompt.txt`, embedded in the PNG, and recorded in the WebP sidecar. Responsive website derivatives originate from this source. No existing artist/Apple artwork is included.

`vinyl-disc.png`, `paper-sleeve.png` and `olive-tape.png` are original 1280 × 1280 isolated components generated separately with the built-in image tool on the same date. The vinyl-journey image was a material/lighting reference. These are separate alpha images for the user's requested exploding-component animation, not slices of the flattened hero. Adjacent prompt files preserve each exact prompt; each original PNG embeds it, and every optimized WebP has a metadata sidecar. Alpha was checked: all three include both transparent and opaque pixels. Existing Night Ferry and Between Stations artwork supplies the two independent cover layers.

`mixtape-hero.png` is an original image generated on 2026-10-15 with the built-in Codex image generation tool. It depicts fictional record sleeves and a cassette; it uses no Apple or artist artwork. It is a marketing illustration, not a product screenshot. Original output is 1536 × 1024 pixels. The project copy is the source for responsive website derivatives.

## Generation prompt

```text
Use case: ads-marketing
Asset type: original wide hero illustration for Groovectl, an open-source Apple Music toolkit for agents, used in a public GitHub README and documentation website.
Primary request: an art-directed tactile still life about making a mixtape: a sculptural ribbon of dark magnetic tape makes an elegant looping path between three square blank record sleeves and one beautiful translucent raspberry cassette. The path feels like a thoughtfully sequenced listening journey. One sleeve has a minimal warm sunset color field, one has a deep olive abstract field, one is warm cream; none resemble an existing album. Tiny raised circular record grooves and realistic paper edges reward close inspection.
Style/medium: refined physical miniature photographed in a studio, warm editorial design, playful but precise materials; matte paper, translucent red plastic and satin magnetic tape, soft contact shadows, fine grain.
Composition/framing: wide landscape 3:2 composition, striking central-to-right arrangement with breathing room at left and around edges; simple pale warm cream background. Clear silhouettes that still read at README size.
Lighting/mood: late afternoon warmth, a curious independent record shop, calm and inviting.
Constraints: no text, lettering, numbers, UI, logos, brand marks, people, music notes, watermarks, device screens or existing album artwork. Keep it original and uncluttered.
```

`mixtape-hero.webp` is the responsive build's optimized derivative of the original PNG, retained for the README. Its exact prompt is recorded in the adjacent metadata sidecar. The editable Groovectl groove marks are project-authored SVG; the website renders the wordmark as text. Apple Music and Cider names identify compatible services and do not imply endorsement.
