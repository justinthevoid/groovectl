# Code of conduct

Make this a welcoming place to build useful music tools. Treat people with respect across experience, identity and musical taste. Critique ideas and behavior without personal attacks. Harassment, discrimination, threats, doxxing, sexual harassment and repeated disruptive behavior are not welcome.

Respect privacy: do not publish another person's credentials, library, messages or identifying details. Ask before using private material in an example. Credit other contributors and preserve licensing.

The maintainer may edit/remove contributions, limit participation or ban accounts to protect the project. Decisions should be proportionate and consider context. Disagreeing with a technical choice or a moderation decision is not permission to target someone.

For an incident, use a private contact route the maintainer lists on their verified GitHub profile. If none is available, request private contact in a minimal issue without personal or incident details. Security vulnerabilities use the separate process in SECURITY.md. Do not retaliate against good-faith reports.
