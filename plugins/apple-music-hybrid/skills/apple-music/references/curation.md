# Creative listening workflows

Use these as musical structures, not mandatory questionnaires or separate tool calls.

**Three-act soundtrack.** Establish place/mood, introduce a deliberate contrast, then
land. Ask about the destination only if missing and consequential. Choose an opener,
a hinge and a closer before filling the middle. Resolve exact versions and check
repeated artists; preserve the arc if a generic sequencing heuristic weakens it.

**Taste bridge.** Start with two supplied songs or artists. Explain a plausible musical
connection in plain language, then find verified recordings that make the path audible.
Never invent a collaboration, instrument credit, place of origin or measured feature.

**Side A / Side B.** Build two short contrasting halves with a purposeful hinge.
Return section boundaries in the description, real total runtime and any tolerance
miss. Do not promise exact duration through unavailable editing/crossfade controls.

**Rediscovery.** Combine bounded library samples, recent listening, heavy rotation or
eligible Replay with explicit anchors. Name the sample limit. Avoid claiming a track
was never played or that a short sample captures the person's entire taste.

**Time capsule.** Preserve requested era/place and verify factual context. Album
rerelease dates can differ from original recording dates. Review remasters and live
versions with the user when they matter rather than discarding every rerelease.

**Cover first.** A brief can start with a place, palette and feeling. Generate one
original sleeve, then curate its soundtrack. Show the actual completed image, retain
its resource ID, and keep playlist creation and artwork application separate.

## Interview examples

- Complete: "45 minutes of clean 1970s soul for dinner, no live versions" → save it,
  choose sensible artist variety, curate and preview; creation is authorized if asked.
- Ambiguous: "something for tonight" → ask about occasion and one musical anchor;
  offer a bounded surprise concept if the person prefers not to choose.
- Discovery: "bridge Kate Bush and Caroline Polachek, strange but warm" → preserve
  anchors, ask duration only if necessary, structure a path and verify recordings.
- Constraint: "surprise me, no explicit songs and no covers" → keep both exclusions;
  do not erase them when selecting a random concept. Verify recording identities.
- Playback: "make a mix, don't play it" → create only if requested, never start transport.
- Artwork only: "give this brief a cover" → generate/check image, no library mutation.

## Finish usefully

Report the verified playlist result, actual runtime, notable version choices and any
unresolved recordings. If a write is unknown/needs_review, report its accepted ID and
inspect rather than retrying. For artwork return the real image or resource, not a
confident description of an image that has not completed. Keep technical diagnostics
out of creative playlist descriptions.
