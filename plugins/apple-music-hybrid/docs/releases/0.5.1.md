# Groovectl 0.5.1 qualification checkpoint

This patch is being qualified after the [0.5.0 public preview](https://github.com/justinthevoid/groovectl/releases/tag/v0.5.0). It is not a claim that every player, image provider or extension host has passed live checks.

Workspace and studio lists now return compact plan/draft summaries instead of repeating whole recording arrays, receipts and interview histories. Select a plan with `inspect_playlist_plan` or a draft with `get_playlist_studio({draft_id})` to retrieve its complete saved data. Tool names, journal payloads, exact-recording verification and uncertain-write protections remain unchanged. The dashboard loads details when selected and exposes saved receipts without automatically retrying music writes.

Linux type/UI checks and the bundle build passed with all 106 tests, including large histories and complete inspector round trips. Multi-platform CI, final package/install scans and actual extension/player checks are tracked in the [qualification ledger](../qualification.md). No charged image call or personal preference/library write is implied by these checks.
