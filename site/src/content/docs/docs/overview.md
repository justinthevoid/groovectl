Groovectl connects an agent to Apple Music discovery, your library and a supported player. The agent chooses the music. Groovectl resolves real recordings, previews changes, saves a durable plan and checks the result.

## Start with the way you listen

- On a Mac, native Music.app library and playback work without a MusicKit key.
- On any supported server OS, MusicKit enables catalog and personal-library APIs.
- Cider adds its authenticated local player and queue API.
- Windows Apple Music has an experimental media-session adapter with fewer controls.
- A VPS can run API-only curation and account tools. It does not become a remote for another computer's player.

Follow **Install and connect** in the sidebar, then the guide for your player. The capability map records implementation and live qualification separately.

## The playlist studio

Begin with a sentence. Use the optional interview when you want ideas. Keep fields you care about, ask the agent for fresh suggestions, or randomize unlocked creative choices. Your intent, exclusions and content policies stay authoritative.

The studio follows **brief → recordings → sequence → cover**. Inspect versions and order before applying a saved playlist plan. Other agents can use the same tools without the interactive UI.

## Release status

This is a pre-public development build. Source installation and reviewed local packages are supported paths; a public npm package or plugin listing must be verified before using a registry install command. Some Windows, Cider, account-write and image-provider paths still require live qualification. See **Capabilities and limits** for those boundaries.
